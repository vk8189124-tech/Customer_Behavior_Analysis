# Customer_Behavior_Analysis
Project Overview

This project demonstrates a complete Data Analytics workflow using Python, MySQL, and Power BI. The goal was to load and analyze a dataset, clean and transform the data, run SQL queries for business insights, and create an interactive dashboard for visualization.

Tools & Technologies Used
Python (Pandas, NumPy, Matplotlib, Seaborn)
MySQL Server
Power BI
Jupyter Notebook
Project Workflow
1. Data Loading
Imported dataset using Python
Read CSV/Excel files with Pandas
Explored dataset structure and data types
2. Exploratory Data Analysis (EDA)
Checked dataset shape and summary statistics
Identified missing values and duplicates
Performed trend and pattern analysis
Created visualizations using Matplotlib and Seaborn
3. Data Cleaning
Handled missing/null values
Removed duplicate records
Corrected inconsistent data formats
Standardized column names and values
4. SQL Analysis (MySQL)
Connected Python with MySQL Server
Imported cleaned dataset into MySQL
Executed SQL queries for data analysis
Used:
SELECT statements
GROUP BY
ORDER BY
Aggregate functions
Joins and filtering
5. Power BI Dashboard
Built an interactive dashboard in Power BI
Added charts, KPIs, and filters
Visualized key business insights
Improved data storytelling and reporting
Key Insights
Identified important trends and patterns in the dataset
Improved data quality through cleaning and preprocessing
Generated actionable insights using SQL and Power BI visualizations
